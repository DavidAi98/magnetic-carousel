# Magnetic Carousel

An interactive 3D physics demo exploring how a steel ball moves above a rotating array of magnets. Built with JavaScript, Three.js, and Vite.

## Features

- Adjust rotation speed, magnet count, arrangement radius, angular span, and magnetic moment.
- View force arrows on the ball and a separate free-body diagram.
- Switch between English and Chinese.

## Controls

- **Left drag:** Pan
- **Right drag:** Rotate
- **Scroll:** Zoom
- **Space:** Pause / Resume
- **Reset button:** Reset the ball

## Physics Model

The simulation uses magnetic dipole fields, induced magnetization, and linear damping. It is a simplified demonstration and does not include ball rotation, contact friction, or magnetic hysteresis.
